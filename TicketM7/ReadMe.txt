********** How to run the  CRM - Ticket Module **********

1. Download the  zip file

2. Extract the file and copy crm folder

3.Paste inside root directory(for wamp wamp/www)

4. Open PHPMyAdmin (http://localhost/phpmyadmin)

5. Create a database with name dbtm

6. Import dbtm.sql file(given inside the zip package in SQL file folder)

7.Run the script http://localhost/TicketM7/index.php (frontend)
